About this dashboard

linux-diag-dashboard runs the linux-diag MCP server in-process and calls its read-only tools on a fixed schedule. It listens on 127.0.0.1 only, inside the same Landlock sandbox as the server. The data endpoint answers only requests that carry the access token from the URL it printed at startup.

  • CPU figures come from one short sample per update, so a single reading can catch a spike. The small line under each headline figure shows the readings since this page was opened.
  • Memory used is total minus available. Page cache counts as available because the kernel frees it when programs need it.
  • Process state: R running, S sleeping, I idle kernel thread, D waiting on I/O.
